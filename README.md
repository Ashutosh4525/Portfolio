# Ashutosh Pal Portfolio

A VS Code-inspired portfolio built with Next.js, React, Tailwind CSS v4, and Zustand. It presents profile, skills, projects, and contact details through a workspace-style interface with tabs, an explorer, layout modes, and a built-in terminal.

## Overview

This project showcases Ashutosh Pal as a full-stack developer with a MERN background and hands-on experience building AI-assisted web applications.

## Features

- VS-inspired portfolio shell with title bar, activity bar, explorer, tabs, and terminal
- Three layout modes: `editor`, `showcase`, and `zen`
- Zustand-powered tab and UI state management
- Theme switching from the status bar
- Responsive design for desktop and mobile
- Structured sections for profile, skills, projects, and contact

## Tech Stack

- `Next.js 16`
- `React 19`
- `Tailwind CSS v4`
- `Zustand`
- `ESLint`
